# Airflow Log Retrieval Issue – Troubleshooting Summary

## Issue
Airflow DAG tasks were executing successfully, but task logs could not be opened from the Airflow UI.

**Error:**
```text
*** Could not read served logs:
Request URL is missing an 'http://' or 'https://' protocol.
```

## Environment
- Airflow Version: 2.7.1
- Executor: CeleryExecutor
- PostgreSQL: Source Database
- Redis: Celery Broker
- Snowflake: Target Data Warehouse
- Docker Compose Deployment

## Investigation Steps

### Verify Running Containers
```bash
docker ps
docker ps -a
```

### Check Airflow Base URL
```bash
docker exec -it airflow-docker-airflow-webserver-1 airflow config get-value webserver base_url
```

Output:
```text
http://localhost:8080
```

### Check Remote Logging
```bash
docker exec -it airflow-docker-airflow-webserver-1 airflow config get-value logging remote_logging
```

Output:
```text
False
```

### Check Worker Log Server Port
```bash
docker exec -it airflow-docker-airflow-webserver-1 airflow config get-value celery worker_log_server_port
```

Output:
```text
8793
```

### Check Worker Hostname
```bash
docker exec -it airflow-docker-airflow-worker-1 hostname
```

### Verify Executor Type
```bash
docker exec -it airflow-docker-airflow-webserver-1 airflow config get-value core executor
```

Output:
```text
CeleryExecutor
```

### Review Webserver Logs
```bash
docker logs airflow-docker-airflow-webserver-1 --tail 100
```

## Fix Applied

Added the following environment variables to `docker-compose.yml`:

```yaml
environment:
  AIRFLOW__WEBSERVER__BASE_URL: http://localhost:8080
  AIRFLOW__LOGGING__WORKER_LOG_SERVER_PORT: 8793
```

## Restart Airflow Services

```bash
docker compose down
docker compose up -d --force-recreate
```

1. All dbt commands in one documented list
No.	Command	Description
1	dbt --version	Display dbt and adapter versions
2	dbt --help	Display available dbt commands
3	dbt debug	Validate dbt configuration and database connection
4	dbt parse	Parse project files and validate configuration
5	dbt deps	Install packages from packages.yml
6	dbt clean	Remove configured clean directories
7	dbt init	Initialize a new dbt project
8	dbt run	Execute all selected models
9	dbt compile	Compile models into executable SQL
10	dbt test	Execute data quality tests
11	dbt build	Build selected resources and run associated tests
12	dbt snapshot	Capture historical data changes
13	dbt seed	Load CSV files into the database
14	dbt docs generate	Generate project documentation
15	dbt docs serve	Start the documentation web server
16	dbt ls	List project resources
17	dbt show	Execute and display a model or SQL query result
18	dbt source freshness	Check source data freshness
19	dbt retry	Retry eligible failed nodes from a previous invocation
20	dbt run-operation	Execute a macro from the command line
